Aktivasi Cloud Sync & Google Login

Untuk menghubungkan web ini dengan Login Google dan Cloud Sync gratis:

  1. Buka Firebase Console (gratis dari Google) & buat proyek baru.
  2. Di menu kiri, aktifkan Authentication → pilih metode Google → Enable.
  3. Di menu kiri, aktifkan Firestore Database → Create database (Test Mode).
  4. Buka Project Settings (ikon gerigi) → daftarkan Web App (</>) → salin kuncinya.
  5. Tempelkan kunci tersebut ke file assets/js/firebase-config.js di proyek Anda.

*Saat ini aplikasi tetap berjalan lancar 100% menggunakan Mode Tamu (Penyimpanan Lokal IndexedDB).
